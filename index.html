▶ 📐 Calculation Methodology

👥 Fellow Counts

Main Cohort (X.0) = Cohort Size parameter
Extension 1 (X.1) = X.0 × Ext 1 Rate
Extension 2 (X.2) = X.1 × Ext 2 Rate

London Fellows = Count × London %
Remote Fellows = Count × Remote %
Berkeley Fellows = Count × (1 - London % - Remote %)

Fellows are active from cohort start date to end date. Location split uses different % for main vs extension cohorts. Remote fellows work remotely (not counted in office space).

🏠 Residency Program

Months 0-5: Base Count
Months 6-11: Base × √(YoY Growth)
Months 12-17: Base × YoY Growth
Months 18-23: Base × YoY Growth × √(YoY Growth)

6-month multiplier = √(YoY Growth)

Residency grows every 6 months using compound growth based on YoY rate.

👔 Research Management Staff

By Program Type (Main/Extension):
Main Fellows = x.0 cohorts + Residency
Extension Fellows = x.1 and x.2 cohorts

Main RMs = ⌈Main Fellows ÷ Main Fellows/RM⌉
Main SRMs = max(⌈Main RMs ÷ RMs/SRM⌉, ⌈Main Fellows ÷ Fellows/SRM⌉)
Ext RMs = ⌈Ext Fellows ÷ Ext Fellows/RM⌉
Ext SRMs = max(⌈Ext RMs ÷ RMs/SRM⌉, ⌈Ext Fellows ÷ Fellows/SRM⌉)

Total RMs/SRMs attributed to locations by fellow distribution

Leads (per team, per location):
Leads from SRMs = ⌈SRMs ÷ SRMs/Lead⌉
Leads from Community = ⌈(CMs+JTs) ÷ (CMs+JTs)/Lead⌉
Leads from PMs = ⌈PMs ÷ PMs/Lead⌉
Leads from Compute = ⌈(CA+RE) ÷ (CA+RE)/Lead⌉
Total Leads = sum of all team leads

RM/SRM ratios differ by program type. RMs/SRMs are attributed to London/Berkeley proportionally based on fellow distribution.

🌐 Global Support Roles

Total Fellows = London + Remote + Berkeley

CMs = ⌈Main Fellows ÷ Main Fellows/CM⌉ + ⌈Ext Fellows ÷ Ext Fellows/CM⌉
JTs = ⌈Main Fellows ÷ Main Fellows/JT⌉ + ⌈Ext Fellows ÷ Ext Fellows/JT⌉
London/Remote Ops = ⌈Location Fellows ÷ Fellows/Ops⌉
Berkeley Ops = Fellows/40 + Staff/10 + Sqft/25k
PMs = Date-based scaling (see Program Team Scaling)
Compute Admins = ⌈Total Fellows ÷ Fellows/CA⌉
REs = ⌈Total Fellows ÷ Fellows/RCE⌉
Recruiters = ⌈Total Fellows ÷ Fellows/Recruiter⌉

Most roles scale with fellow count. PMs use explicit headcount schedule. Berkeley ops uses additive formula.

📈 Staff Ratchet (No Layoffs)

For each role and month:
Actual Staff = max(Calculated Need, Previous Max)

Running Max updates each month

Staff counts only grow over time (no layoffs). Each month's staff is at least the previous maximum.

📅 Hiring Timeline

Onboarding Start = Month Start - (Onboarding Weeks × 7 days)
Rounded to previous Monday

Hire Delta = max(0, Need - Running Max)
Gap = Need - Current Staff (at start)

Shows when to start hiring to have staff ready by cohort start.

🏢 Office Space (Berkeley)

All Fellows (3 locations):
London = Count × London %
Remote = Count × Remote % (no office)
Berkeley = Count × (1 - London % - Remote %)

Staff:
Berkeley Staff × (1 - Staff Remote %)

Total:
People = In-office Staff + Berkeley Fellows + Visitors
Sq Ft Needed = People × Sq Ft/Person
Floor 3 Needed when People > Fl 1+2 Capacity

Remote fellows don't need office space at any location. Floor 3 decision = need date − lead time.

📊 YoY Growth Stats

Max Fellows (Year) = max of monthly fellows in year
Max Staff (Year) = max of monthly staff in year

YoY Growth = Max(Year N+1) ÷ Max(Year N)

Displayed as: 2026→27 / 2027→28

Uses peak values from each year, not averages.
